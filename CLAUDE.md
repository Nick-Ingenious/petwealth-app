# PetWealth app

## Design system

All UI work in this repo (customer portal, admin, emails, dashboards, any page or component) follows the Petwealth design skill at `.claude/skills/petwealth-design/`. Load it before designing, building or reviewing anything visual, or writing copy that will appear in the UI.

- Start with `SKILL.md` (universal rules), then the channel reference: `web-landing-pdp.md` for portal/app pages, `dashboards-and-data.md` for admin and data views, `email-and-sms.md` for transactional email.
- Run `references/review-checklist.md` before calling UI work done.
- No em dashes in any copy, comments or replies.
